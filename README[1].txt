LPILATES 홈페이지 파일

GitHub 저장소 이름은 elpilates-homepage 그대로 사용해도 됩니다.
홈페이지에 표시되는 업체명은 모두 LPILATES로 수정했습니다.

업로드:
1. GitHub 저장소에서 Add file > Upload files
2. 이 ZIP 안의 index.html과 README.txt를 업로드
3. Commit changes
4. Settings > Pages > Deploy from a branch
5. Branch: main / Folder: /(root) > Save

참고:
- 사이트 표시 상호: LPILATES
- 지역: 대구 달서구 월성동(신월성)
- 네이버 플레이스 링크: 등록된 업체 페이지
- 상세 주소, 전화번호, 운영시간, 가격 등 확인되지 않은 정보는 임의로 넣지 않았습니다.
